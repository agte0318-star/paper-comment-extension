Support

Paper Comment Extension beta support page

Paper Comment Extension is a browser extension for article-level comments and ratings on academic papers. This page collects the public support links for installation issues, paper detection problems, account questions, and content reports.

Get Help

  • Open a GitHub issue for bugs, paper detection problems, or feature requests.
  • Open the public discovery page to check whether public activity is loading.
  • Read the privacy policy for data collection and storage details.

Useful Details To Include

  • The extension version shown in the popup.
  • The article URL or DOI/arXiv ID where the issue happened.
  • Whether you were using the sidebar, popup, profile page, or public paper page.
  • A short description of what you expected and what happened instead.

Content Reports

Signed-in users can report comments and replies directly inside the extension. Reports are reviewed through the admin moderation tools. For urgent moderation or privacy issues, open a GitHub issue and avoid posting private personal information.
